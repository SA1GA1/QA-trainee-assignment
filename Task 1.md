# Задание 1

P0 — критический, P1 — высокий, P2 — средний, P3 — низкий

## Заполненная форма редактирования

1. Дублируется заголовок "Внешний вид"
    Приоритет: P3
    Расположение: между блоками "Состояние" и "Фотографии"
    Фактический результат: заголовок "Внешний вид" отображается дважды
    Ожидаемый результат: заголовок "Внешний вид" отображается единожды

## Карточка продавца

1. В заголовке объявления указано неверное название
    Приоритет: P2
    Расположение: заголовок объявления над строкой со статусом
    Фактический результат: "Диван прямой QA Sofa 2026 раскладной"
    Ожидаемый результат: "Диван угловой модульный QA Sofa 2026 раскладной", как в форме редактирования

2. Нет информации на графике при наличии просмотров объявления
    Приоритет: P2
    Расположение: "Статистика за неделю" во вкладке "Просмотры"
    Фактический результат: показывается 8 просмотров, но на графике нет отображения данной информации
    Ожидаемый результат: на графике видно, сколько просмотров было в каждый день за период

3. Первой фотографией стоит не главное фото
    Приоритет: P2
    Расположение: блок с фотографиями, под статистикой за неделю
    Фактический результат: Стоит второе фото из формы редактирования
    Ожидаемый результат: первым стоит фото, отмеченное главным в форме редактирования

4. Отображаются особенности, не указанные в форме
    Приоритет: P2
    Расположение: блок "Характеристики"
    Фактический результат: Написано про "Ящик для белья, Подлокотники, Подушки", хотя таких данных в форме редактирования не было
    Ожидаемый результат: Отображаются только те особенности, которые были указаны в форме редактирования

5. Поле описания содержит лишний текст об особенностях товара
    Приоритет: P2
    Расположение: блок "Описание"
    Фактический результат: Второе предложение содержит текст "Угловой раскладной диван с ящиком для белья, подлокотниками и подушками"
    Ожидаемый результат: Второе предложение содержит только текст "Угловой раскладной диван", как в форме редактирования

6. Отображается лишняя цифра "6" на графике
    Приоритет: P3
    Расположение: блок "Статистика за неделю", левая шкала графика
    Фактический результат: цифра "6" перекрывает часть шкалы графика, видна обрезанная часть другой цифры
    Ожидаемый результат: шкала графика не должна быть перекрыта лишними элементами

7. В заголовке скидки отображается "test_sale_ops"
    Приоритет: P3
    Расположение: блок "Привлекайте покупателей", заголовок второго предложения о скидках
    Фактический результат: отображается заголовок "Скидки в test_sale_ops"
    Ожидаемый результат: указано название акции

8. Не отображается иконка для скидки
    Приоритет: P3
    Расположение: блок "Привлекайте покупателей", иконка над заголовком второго предложения о скидках
    Фактический результат: вместо иконки отображается значок ошибки загрузки
    Ожидаемый результат: над заголовком отображается иконка скидки
