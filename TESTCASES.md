# Тест-кейсы для задания 2.1 (API)

## API-01. Регистрация пользователя с новым именем

- Тип проверки: позитивная, функциональная
- Метод и путь: `POST /api/1/register`
- Автотест: `test_auth.py::test_api_01_register_with_unique_username`
- Предусловия: тестовый стенд доступен. Для запроса не нужен bearer-токен
- Тестовые данные: сгенерировать уникальный `username` для каждого запуска, например `qa_` и 12 символов UUID. Подготовить валидный `password`

Шаги:

1. Отправить `POST /api/1/register` без заголовка `Authorization`. В JSON передать подготовленные `username` и `password`
2. Проверить HTTP-статус и поля ответа

Ожидаемый результат:

- HTTP-статус `201 Created`
- В теле ответа есть `id` в виде целого числа
- Значение `username` в ответе совпадает с отправленным

Шаги:

Ожидаемый результат:
