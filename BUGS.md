## BUG-01. При нечисловой цене API сообщает, что тело объявления не передано

- Серьёзность: низкая
- Окружение: тестовый стенд `https://qa-internship.avito.com`
- Связанный тест-кейс: API-10

### Шаги воспроизведения

1. Зарегистрировать тестового пользователя и получить его токен через `POST /api/1/autorize`
2. Подготовить JSON для создания объявления с `sellerID` этого пользователя и заменить значение `price` на строку `"abc"`
3. Отправить `POST /api/1/item` с этим JSON и токеном пользователя

### Фактический результат

Сервер возвращает `400 Bad Request`. В поле `status` указано `не передано тело объявления`, хотя в запросе есть JSON с данными объявления

### Ожидаемый результат

Сервер возвращает `400 Bad Request` и сообщает, что поле `price` должно содержать число

## BUG-03. API считает переданные нулевые счётчики статистики отсутствующими

- Серьёзность: средняя
- Окружение: тестовый стенд `https://qa-internship.avito.com`
- Связанный тест-кейс: API-22

### Шаги воспроизведения

1. Получить валидный токен тестового пользователя через `POST /api/1/autorize`
2. Подготовить тело объявления со своим `sellerID`, уникальным названием и положительной ценой. В `statistics` поставить `0` в одном из полей `likes`, `viewCount` или `contacts`, оставив остальные счётчики положительными
3. Отправить `POST /api/1/item` с подготовленным телом и токеном
4. Повторить запрос для каждого из остальных счётчиков с новым названием объявления

### Фактический результат

Сервер возвращает HTTP `400 Bad Request` и сообщает, что счётчик с переданным числом `0` обязателен. Проблема воспроизводится по отдельности для `likes`, `viewCount` и `contacts`. Например, при `likes: 0` в `result.message` указано `поле likes обязательно`. При запросе со всеми тремя нулями сервис также сообщает об ошибке в `likes`

### Ожидаемый результат

При допустимом значении `0` сервер создаёт объявление с отправленными счётчиками и возвращает `200 OK`. Если для какого-либо счётчика предусмотрено положительное минимальное значение, ошибка сообщает об ограничении на значение этого поля
